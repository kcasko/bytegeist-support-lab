\# Coding Agent Development Log



\## Project



ByteGeist Support Lab



\## Hackathon



AWS Zero to Shipped 2026



\## Goal



Build an AWS-hosted IT troubleshooting training platform where learners

investigate simulated support incidents and receive AI-assisted feedback.



\## Development Log



\### Project Initialization



Created the initial React frontend using Vite and established the repository

structure for the frontend, backend, infrastructure, and AWS documentation.



\### Planned AWS Architecture



\- AWS Amplify Hosting

\- Amazon API Gateway

\- AWS Lambda

\- Amazon DynamoDB

\- Amazon Bedrock



\### Coding Agent



The project will use a coding agent connected to AWS during development and

deployment. AWS connection evidence and screenshots will be documented in

`docs/aws-connection.md`.
